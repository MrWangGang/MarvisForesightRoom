# Marvis Foresight Room

**一个用于群体 AI 推演的虚拟讨论室。**

Marvis Foresight Room 是一个实验性的多人物讨论空间。它尝试让多个 AI 人物像一个小型人类群体一样共同思考。

你不是向一个模型索要一个答案，而是创建一个房间，生成一组人物，让他们争吵、结盟、拆分想法、互相质疑，并在不断碰撞之后逐渐收束。

你可以访问 http://49.235.185.187:8080/ 体验一下

![Marvis Foresight Room](docs/screenshots/live-room.webp)

## 这是什么

Marvis Foresight Room 是一个多人物推演环境。

你给它一个主题，它会围绕这个主题生成一组不同的人。每个人都有自己的传记、人格、风险偏好、社会关系、世界观和说话方式。

然后，讨论开始。

这些人物不会只是机械地轮流输出漂亮答案。他们更像真实讨论里的人：

- 有人先扔出一个粗糙想法；
- 有人立刻反驳；
- 有人把冲突带向新的分支；
- 临时联盟出现；
- 反对意见改变方向；
- 脆弱的想法被淘汰；
- 更强的路径留下来；
- 群体慢慢走向一个决定。

这个项目的目标不是立刻生成一个完美答案。

它的目标是让“答案形成的过程”变得可见。

## 为什么做

大多数 AI 产品隐藏了思考里最重要的部分：答案出现之前的挣扎。

真实决策很少是线性的。它往往来自压力、分歧、犹豫、重构和妥协。一个单独的回答当然有用，但它经常跳过了让想法变强的社会过程。

Marvis Foresight Room 想探索一种不同的 AI 界面：

**不是一个助手，而是一整个房间的视角。**

它适合那些“过程和结果同样重要”的问题：

- 商业策略；
- 产品方向；
- 个人规划；
- 创意脑暴；
- 风险复盘；
- 未来场景；
- 决策预演；
- 想法压力测试。

## 体验

### 房间

界面围绕一个虚拟办公室展开。人物会进入、睡眠、醒来、发言，然后回到背景里等待下一次参与。

![Sleeping Office](docs/screenshots/sleeping-office.webp)

### 对话

每一次发言都会成为推演轨迹的一部分。你可以观察一个想法如何分裂、碰撞、变形，又如何回到主线。

![Chat Info](docs/screenshots/chat-info.webp)

### 主理人

Marvis 是这个房间的主理人。

它不是简单的总结者。它会观察房间里的节奏，注意哪个分支已经变得重复，谁被忽略了，什么时候应该让某两个人继续争论，什么时候应该询问大家是否可以收束。

当讨论接近最大轮数仍然没有自然收束时，Marvis 会强制介入：停止继续扩散，整理候选路径，要求所有人投票，并把结果转成最终方向。

## 核心想法

### 先有人，再讨论

一个讨论室不能从空角色开始。

讨论开始前，系统会先根据当前主题生成完整的人物群像。这些人不是固定职位，也不是套壳模板，而是被当前问题塑造出来的临时人物。

每个人物都可以拥有：

- 唯一身份；
- 人格；
- 个人传记；
- 人口统计特征；
- MBTI 类型；
- 职业背景；
- 风险偏好；
- 行为模式；
- 社交关系；
- 意识形态立场；
- 说话方式。

核心很简单：不同的人不应该只是同一个助手换了几个标签。

### 群体涌动，而不是轮流发言

对话不应该像机械排队。

下一位发言者应该像真实群聊里自然跳出来的人：想反驳的人，想保护某个想法的人，想转向的人，想挑衅的人，或者想把一个快散掉的想法救回来的人。

这个房间会尽量保留这种自然感，同时避免少数几个人长期霸屏。

### 收束需要共识

讨论不应该因为“消息够多了”就结束。

自然结束只发生在参与者明确认为主要分支已经讨论过、群体可以收束的时候。

如果他们始终无法自然达成一致，房间会使用最大轮数作为安全边界。接近上限时，Marvis 会介入，让大家停止扩散并开始投票。

## 可以用来做什么

当你不只是想要一个答案，而是想看一个答案如何形成时，可以使用 Marvis Foresight Room。

例如：

- “一个人如何月入五万？”
- “下一个产品方向应该选哪个？”
- “这个创业想法最可能死在哪里？”
- “小团队应该怎样使用 AI，才不会变得更混乱？”
- “这个计划最强和最弱的版本分别是什么？”
- “不同背景的人会围绕这个问题争论什么？”

## 当前状态

这是一个早期实验项目。

它已经可以作为本地原型使用，但更大的目标还在后面：更丰富的人格、更深的记忆、更好的推演图、更真实的群体行为，以及更强的“从讨论到行动”的能力。

你会看到粗糙的地方，也可能看到奇怪的对话。

这正是实验的一部分。

## 本地运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp config.example.py config.py
python main.py
```

然后打开：

```text
http://localhost:8080
```

启动前需要在 `config.py` 中填写你自己的模型 API Key。
